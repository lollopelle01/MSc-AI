Given L=[a_1, ..., a_n], prove that the function

minmax(L) = (x,y) where x=min(L) and y=max(L)

is in FP.
=====================================================

INPUT: L=[a_1, ..., a_n]
OUTPUT: (b,c)

PSEUDOCODE:
min <- a_1			1
max <- a_1			1
for i in [1,n] do 		O(n)
	if x < min then	1
		min <- x		1
	if x > max then	1
		max <- x		1
return (min,max)		1
= 2+4*O(n) ~ O(n) 

1) Correctness: yes, explores all the elements
2) Tot num of instructions: polynomial
3) Size of intermediate results: 
	min <= |input|
	max <= |input|
	i <= |input|
3) Time execution of instruction: polynomial
	• variable assignments
	• natural number comparisons
==> Pseudocode works in polynomial time ==> minmax(•) is in FP
