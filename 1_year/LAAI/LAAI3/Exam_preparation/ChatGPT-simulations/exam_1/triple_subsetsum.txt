INPUT: A={a1, ..., an}, t
OUTPUT: True if exists S={a_k, a_j, a_z} in A so sum(S)=t

PSEUDOCODE:
for a1 in A:
   for a2 in A-{a1}:
      for a3 in A-{a1, a2}:
          if (a1+a2+a3)==t:
             return True
return False

1) The input is easily encodable as binary string
2) The pseudocode works in O(|A|^3)=O(n^3)
3) Intermediate results are just integers
4) Intermediate operations are linear

SO the problem is in P.
