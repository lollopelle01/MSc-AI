INPUT: G=(V,E)
CERTFICATE: proposal clique W
VERIFER:
perf_squares = [n*n for n in range(1..|W|+1)]
if |W| not in perf_squares:
   return False
for v in W:
   for v' in W-{v}:
       if (v,v') in E:
          return False
return True

1) The certificate is smaller than V
2) The verifier works in O(|W|^2)=O(|V|^2)

The problem is in NP.

Moreover we can reduce clique <_p square_clique by using the polytime redunction:
if k perfect square ==> G'=G
else:
- Given k' the smallest perfect square s.t. k'>k
- Add k'-k fully interconnected nodes and connect each of them to the V nodes
In this way G' will have a k + (k'-k) = k' clique

The problem is so NP-hard and so NP-complete
